Project: foodbuddy

Overview:
- A Next.js 16 application using the App Router and TypeScript.
- Designed as a hostel/college mess management system.
- Uses Firebase for authentication, Firestore, Storage, and Google sign-in support.
- Includes role-based dashboard sections for students, managers, and authority staff.
- Uses Tailwind CSS v4 with PostCSS and custom UI styling.

Login and Authentication:
- app/login/page.tsx
  - Client-side login page.
  - Uses Firebase email/password sign-in.
  - Fetches the `users` document from Firestore to determine role.
  - Routes users by role:
    - student -> /student
    - manager -> /manager
    - authority or warden -> /authority

Summary:
This is a Firebase-backed mess management system for students, managers, and authority users. The app is built on Next.js App Router, uses TypeScript, Tailwind CSS, and provides role-based dashboards, QR attendance workflows, feedback forms, menu displays, complaints tracking, hygiene reporting, and notices.
